# Artbook
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
A video and image creator collecting visual inspiration for illustration projects.

## Product Purpose
Upload an image, get a short art-style name and useful internet search keywords, and keep the image in a reusable style library. Matching styles collect multiple images. Empty styles support discovery before collecting references.

## Capabilities and Constraints
Styles distinguish specific visual treatments rather than broad media. Searchable visual tags connect related treatments without merging them. Existing references can be re-identified individually.
Imports also accept public direct PNG, JPEG and WebP URLs, Pinterest pin URLs, and pin.it share links. Imported references retain their original source URL. Other webpage URLs are not supported.

Use the owner's Codex subscription allowance. Persist images and style records on this computer. Classification is an estimate and must be correctable. The user selected a light gallery with large image references.

## Stack
Implementation assumption: local Node.js server with plain HTML/CSS/JavaScript, using the installed ChatGPT-authenticated Codex CLI. No API key billing or cloud hosting.
